# HW2 — Банковская система (BelarusBank)

Привет! Сделал домашку. Все требования выполнены: UI на JavaFX, база данных H2, имена белорусские, валюта BYN.

## 🚀 Как запустить

Проект собран на Maven (Java 17).

1. Открой терминал в папке с проектом.
2. Запусти команду:
```bash
mvn clean javafx:run
```
3. Или открой проект в IDEA и запусти класс **BankApplication**.

## ⚡ Ответы на вопросы

### 1. Что такое UUID?
UUID — это универсальный уникальный идентификатор. Это длинная строка с цифрами и буквами, сгенерированная случайным образом. Вероятность того, что два UUID совпадут, практически нулевая. Это лучше, чем , потому что позволяет создавать уникальные ключи на разных устройствах без синхронизации.

### 2. Архитектура: "Индекс списка как ID"
**Вопрос:** Нормально ли в транзакции указывать номер счета в списке (индекс)?
**Ответ:** **Нет, это плохая практика.** Списки меняются: если удалить первый счет, второй станет первым. Транзакция отправится не туда.
**Решение:** Ссылаться строго на уникальный ID счета (). В моем коде сделано именно так.

### 3. Принципы SOLID
*   **S:** Разделил логику:  работает с БД,  с логикой,  с UI.
*   **O:** Новые операции добавляются через новые классы команд (паттерн Command), не меняя старый код.
*   **L/I/D:** Везде используются интерфейсы (, ) вместо жестких зависимостей.

### 4. Паттерны проектирования
*   **Command:** Каждая операция — это объект (Deposit, Withdraw).
*   **Factory:** Фабрика создает нужную команду по выбору в меню.
*   **Observer:** UI автоматически обновляется при изменении данных.
*   **Visitor:** Используется для глобального аудита банка.
*   **Singleton:**  (одно подключение на всех).

### 5. Асинхронность
*   Операции выполняются в фоне через , чтобы UI не зависал.
*   Для защиты от гонки потоков внутри  используется . Это гарантирует, что деньги не исчезнут при одновременном доступе.
