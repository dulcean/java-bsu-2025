## Ответы на вопросы лабораторной

### 1. Зачем нужны Java и Docker?

- **Java** — это язык программирования и платформа, позволяющая создавать кроссплатформенные приложения. Она нужна для написания надёжного и масштабируемого кода, который одинаково работает на разных операционных системах.  
- **Docker** — инструмент для контейнеризации приложений. С его помощью можно собрать проект с зависимостями в единый контейнер и запускать его на любой машине без проблем с настройкой окружения.
