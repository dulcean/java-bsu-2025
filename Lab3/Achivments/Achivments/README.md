## 2. Техническая реализация (Архитектура)

Проект реализован на базе **трехзвенной архитектуры**, что потребовало настройки взаимодействия между независимыми слоями:

### 1) Фронтенд
Разработан интерактивный интерфейс на базе HTML5 и CSS3.
*   Реализован асинхронный механизм обмена данными с сервером через **JavaScript Fetch API**.
*   Интегрирована визуальная составляющая (требование по **аниме-стилистике**) для улучшения UX.
*   Создана дополнительная «шпионская» страница (`spy.html`) для тестирования и демонстрации механизмов междоменных запросов (**CORS**).

### 2) Бэкенд
Приложение построено на фреймворке **Spring Boot 4.0.1** (экспериментальная ветка) с использованием **Java 23**.
*   **REST Controller:** Реализованы эндпоинты для обработки GET и POST запросов.
*   **Data Access Layer (JPA):** Настроен слой абстракции над базой данных через Spring Data JPA для автоматической генерации SQL-запросов.
*   **CORS Configuration:** Проведена настройка политики Cross-Origin Resource Sharing (`@CrossOrigin`) для обеспечения доступа шпионской странице.

### 3) База данных
Использована реляционная СУБД **PostgreSQL 15**. Спроектирована схема таблицы `achievement` с автоматической генерацией ID и фиксацией временных меток (Timestamp) на уровне сервера.

## 3. Инфраструктура и запуск (Docker)

Весь проект полностью контейнеризирован:
1.  **Dockerfile:** Сборка образа приложения на базе OpenJDK.
2.  **Docker Compose:** Манифест, объединяющий приложение и БД в единую изолированную сеть.
3.  **Автоматизация:** Благодаря `spring-boot-docker-compose`, база данных поднимается автоматически при запуске проекта из IDE.

### Алгоритм работы:
1.  **Инициализация:** При запуске Spring Boot проверяет состояние БД и через Hibernate `ddl-auto` создает таблицы.
2.  **Request:** Пользователь вводит достижение -> JS формирует JSON -> POST на сервер.
3.  **Processing:** Spring десериализует JSON в Entity, ставит время и сохраняет в Postgres.
4.  **Sync:** Фронтенд делает GET-запрос, обновляя список достижений без перезагрузки.
5.  **CORS Test:** Шпионская страница успешно тянет данные с API, подтверждая корректность настройки безопасности.
